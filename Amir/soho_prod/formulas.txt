================================================================================
  3. TOTAL POR CLIENTE
================================================================================

  Base:   Nextphone 14072026 / Móvil sin fijo 02072026

  TOTAL = MONTO - DESCUENTO

  Donde:
    MONTO    = Valor base del plan/servicio (ej: 15, 18)
    DESCUENTO = Descuento aplicado (ej: 0, 5, 10)
    TOTAL    = Monto final facturado al cliente

  Ejemplo:
    MONTO = 15, DESCUENTO = 0 → TOTAL = 15
    MONTO = 18, DESCUENTO = 3 → TOTAL = 15


================================================================================
  4. MRC - MONTHLY RECURRING CHARGE
================================================================================

  Hoja:   Ventas Moviles / Ventas Fijo / lineas facturadas

  MRC (Monthly Recurring Charge) = Valor del plan

  El plan se identifica por código numérico (ej: 20 = $20/mes).

  MRC_Actual = Valor del plan vendido (según código)
  MRC_Anterior = Valor del plan anterior del cliente
  Incremento_MRC = MRC_Actual - MRC_Anterior

  Para ventas convergentes (Fijo + Móvil + Internet):
    MRC_Total = MRC_Fijo + MRC_Movil + MRC_Internet

  Para Winback (clientes recuperados):
    MRC_Winback = MRC_Acum (del cliente antes de irse)
    Se busca recuperar al cliente ofreciendo plan similar o mejor


================================================================================
  5. VENTAS POR EJECUTIVA
================================================================================

  Conteo de ventas por ejecutiva/agente:

  En Excel:
    = COUNTIF(rango_ejecutivas, nombre_ejecutiva)

  En Python (equivalente):
    ---------------------------------------------------------------
    from collections import Counter
    ventas_por_ejecutiva = Counter()
    for row in datos:
        ventas_por_ejecutiva[row['Ejecutiva']] += 1

  Ranking de ejecutivas:
    ---------------------------------------------------------------
    sorted(ventas_por_ejecutiva.items(),
           key=lambda x: x[1], reverse=True)


================================================================================
  6. TASA DE CONVERSIÓN DE LLAMADAS (Vici)
================================================================================

  Hoja:   Vici (Datos del sistema Vici Dialer/Asterisk)

  a) Llamadas Efectivas = COUNTIF(Status, "EFECTIVO")
  b) Llamadas No Efectivas = COUNTIF(Status, "No Cierre Asesor")
                           + COUNTIF(Status, "No Cumple Condiciones")
                           + COUNTIF(Status, "NPC")
  c) Total Llamadas = COUNT(rango_fechas)

  d) Tasa de Conversión = (Efectivas / Totales) × 100

     Ejemplo:
       50 efectivas de 200 totales
       → (50/200) × 100 = 25% de conversión

  e) Intentos por número = COUNTIF(phone_number_dialed, número)
     (Cuantas veces se marcó cada teléfono)

  f) Duración promedio de llamada:
     = AVERAGE(length_in_sec) / 60  → minutos
