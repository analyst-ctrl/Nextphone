3) FORMULAS (TODAS) + VALORES DE JULIO CALCULADOS
----------------------------------------------------------------
Datos base de julio usados en el calculo:
  - 'Vici'   : 3,535 llamadas
  - 'Formas' : 1,039 gestiones (filas de datos)
  - 'Base'   : 33,764 cuentas | Mora 10,549 | Cero Pago 2,581
               | Mora Real 869 | Al dia 19,765

 Columnas de 'Formas' (julio):
   A = Marca temporal | B = Agente | C = Numero celular | D = Cuenta
   E = Identificacion (cedula) | F = Campania | G = Canal
   H = Escenario | I = Motivo | J = Fecha promesa de pago
   K = Monto de promesa de pago | L = Realiza el pago (si/no)
   M = Fecha de Pago | N = Monto pagado | O = Tiempo de mora (dias)

 Columnas de 'Base' (julio):
   A = numero_contrato | S = ESTATUS (Al dia/Mora/Cero Pago/Mora Real)


------------- FUNNEL (DASHBOARD2) -------------

 Asignadas  (cuentas unicas en 'Base' con ESTATUS Mora/Cero Pago)
   =SUMPRODUCTO((ESTATUS rango="Mora")+(ESTATUS rango="Cero Pago"))
   VALOR JULIO (Mora+Cero):         13,130
   Si se incluye "Mora Real" (869): 13,999
   OPCION HISTORICA (gerencia):     3,566  (usar si se conserva
                                     la base de asignadas anterior)

 Gestionadas  (cuentas unicas con al menos 1 gestion en 'Formas')
   =SUMPRODUCTO(('Formas'!D2:D2000<>"")/COUNTIF('Formas'!D2:D2000,'Formas'!D2:D2000&""))
   VALOR JULIO: 948

 Contactadas  (registros con escenario de contacto real, NO son:
   Correo de voz, No contactado, Numero equivocado, Mensaje a tercero)
   =COUNTIFS('Formas'!H2:H2000,"<>Correo de voz",
             'Formas'!H2:H2000,"<>No contactado",
             'Formas'!H2:H2000,"<>Numero equivocado",
             'Formas'!H2:H2000,"<>Mensaje a tercero")
   VALOR JULIO: 650

 Promesas  (registros donde "Fecha promesa de pago" NO esta vacia)
   =COUNTA('Formas'!J2:J2000)-COUNTBLANK('Formas'!J2:J2000)
   VALOR JULIO: 56

 Pagos  (registros donde "Realiza el pago" = si)
   =COUNTIF('Formas'!L2:L2000,"si")
   VALOR JULIO: 364

 % PROMESA
   = Promesas / Asignadas
   VALOR JULIO: 56 / 13,130 = 0.43%
   (con Asignadas=3,566 historico: 1.57%)
   Mayo: 3.22% | Junio: 5.08%


------------- RESUMEN EJECUTIVO (hoja datos) -------------

 HC (cantidad de agentes)
   =SUMPRODUCTO(('Formas'!B2:B2000<>"")/COUNTIF('Formas'!B2:B2000,'Formas'!B2:B2000&""))
   VALOR JULIO: 1  (Lili Velez)

 Cuentas asignadas
   = Asignadas (del funnel)
   VALOR JULIO: 13,130   (o 3,566 si se usa opcion historica)

 Cartera ($)
   CRITERIO CORREGIDO (metodologia historica):
   =SUMAPRODUCTO(('Formas'!J2:J2000<>"")*'Formas'!K2:K2000)
   (equivale al Total de Promesa de Pago del reporte)
   VALOR JULIO: $2,283.08
   Mayo: $4,667.45 | Junio: $6,890.04

 Recuperacion ($)  (suma de Monto pagado donde pago = si)
   =SUMAR.SI('Formas'!L2:L2000,"si",'Formas'!N2:N2000)
   VALOR JULIO: $12,785.67

 % Recuperacion
   = Recuperacion / Cartera
   VALOR JULIO: 12,785.67 / 2,283.08 = 560.02%
   ATENCION: >100% porque julio recupero mucho mas de lo prometido
   (364 pagos vs solo 56 promesas registradas). Ver alertas.
   Mayo: 35.81% | Junio: 117.33%

 Contactabilidad
   = Contactos / Llamadas
   VALOR JULIO: 650 / 3,535 = 18.39%
   Mayo: 11.88% | Junio: 43.54%

 RPC (contactos productivos, escenarios con RPC=1):
   Cliente al dia | Cuenta cesada | Cliente ocupado | Volver a llamar
   Lenguaje inapropiado | Incidente herramienta | Persona detenida
   =SUMAPRODUCTO(( 'Formas'!H2:H2000="Cliente al dia" )
                +( 'Formas'!H2:H2000="Cuenta cesada" )
                +( 'Formas'!H2:H2000="Volver a llamar" )
                +( 'Formas'!H2:H2000="Cliente con lenguaje inapropiado" )
                +( 'Formas'!H2:H2000="Persona en prision" ))
   VALOR JULIO: 348 + 112 + 1 + 1 + 1 = 463

 % RPC
   = RPC / Contactos
   VALOR JULIO: 463 / 650 = 71.23%
   Mayo: 80.96% | Junio: 84.89%

 Promesas
   = Promesas (del funnel)
   VALOR JULIO: 56

 Promesas cumplidas
   =COUNTIF('Formas'!L2:L2000,"si")
   VALOR JULIO: 364
   ATENCION: supera a las promesas (364 > 56). Indica pagos
   registrados sin promesa previa en el formulario (ver alertas).

 % Cumplimiento
   = Promesas cumplidas / Promesas
   VALOR JULIO: 364 / 56 = 650.00%  (fuera de rango, ver alertas)
   Mayo: 79.13% | Junio: 55.25%
