4) FORMULAS (TODAS) PARA CADA INDICADOR
----------------------------------------------------------------
Convencion de hojas (crear estas pestanas en el reporte):
  'Vici'   = CALL REPORT JULIO (llamadas)
  'Formas' = LLAMADAS SALIENTES JULIO (gestiones)
  'Base'   = cartera asignada (NEXTPANAMA/INNOVATEK/LLAMAYA)

------------- FUNNEL (DASHBOARD2) -------------
 Asignadas
   =COUNTA('Base'!A2:A50000)
   o mejor (contar cuentas unicas, sin repetidos):
   =SUMPRODUCTO(('Base'!A2:A50000<>"")/COUNTIF('Base'!A2:A50000,'Base'!A2:A50000&""))

 Gestionadas  (cuentas unicas que tienen al menos 1 gestion)
   =SUMPRODUCTO(('Formas'!D2:D5000<>"")/COUNTIF('Formas'!D2:D5000,'Formas'!D2:D5000&""))
   (columna D = Cuenta en Formas; si no, usar la cedula o el
    numero de celular, lo que identifique la cuenta)

 Contactadas  (registros con escenario de contacto real, NO son:
   Correo de voz, No contactado, Numero equivocado,
   Mensaje a tercero)
   =COUNTIFS('Formas'!H2:H5000,"<>Correo de voz",
             'Formas'!H2:H5000,"<>No contactado",
             'Formas'!H2:H5000,"<>Numero equivocado",
             'Formas'!H2:H5000,"<>Mensaje a tercero")
   (columna H = Escenario)

 Promesas  (registros donde "Fecha promesa de pago" NO esta vacia)
   =COUNTIFS('Formas'!J2:J5000,"<>",
             'Formas'!J2:J5000,"<>Fecha  promesa de pago")
   o =COUNTA('Formas'!J2:J5000)-COUNTBLANK('Formas'!J2:J5000)
   (columna J = Fecha promesa de pago)

 Pagos  (registros donde "Realiza el pago" = si)
   =COUNTIF('Formas'!L2:L5000,"si")
   (columna L = Realiza el pago)

 % PROMESA
   = Promesas / Asignadas
   Mayo:  115 / 3,566  = 3.22%
   Junio: 181 / 3,566  = 5.08%

------------- RESUMEN EJECUTIVO (hoja datos) -------------
 HC (cantidad de agentes)
   =SUMPRODUCTO(('Formas'!B2:B5000<>"")/COUNTIF('Formas'!B2:B5000,'Formas'!B2:B5000&""))
   (columna B = Agente)

 Cuentas asignadas
   = Asignadas (del funnel)

 Cartera ($)
   =SUMA('Base'!saldo)   donde saldo = monto_cuotas x
                         (cuotas totales - Cuotas_Pagadas),
   o si la base trae Monto_Vencido / Monto_Total:
   =SUMAR.SI('Base'!ESTATUS,"Mora",'Base'!Monto_Total)
   + SUMAR.SI('Base'!ESTATUS,"Cero Pago",'Base'!Monto_Total)
   NOTA: Junio uso Cartera = $6,890.04 y Mayo $4,667.45;
         validar que el calculo reproduzca esos numeros.

 Recuperacion ($)  (suma de Monto pagado donde pago = si)
   =SUMAR.SI('Formas'!L2:L5000,"si",'Formas'!N2:N5000)
   (columna N = Monto pagado)

 % Recuperacion
   = Recuperacion / Cartera
   Mayo: 1,671.46 / 4,667.45 = 35.81%
   Junio: 8,084.35 / 6,890.04 = 117.33%

 Contactabilidad
   = Contactos / Llamadas
   Mayo: 772 / 6,496  = 11.88%
   Junio: 940 / 2,159 = 43.54%

 RPC (numero de contactos productivos)
   = contactos cuyo escenario tiene RPC=1 segun tabla Ref:
     6002 Cliente al dia     6003 Cuenta cesada
     6005 Cliente ocupado    6007 Volver a llamar
     6008 Lenguaje inapropiado  6009 Incidente herramienta
     6011 Persona detenida
   (en Excel:
   =SUMAPRODUCTO(( 'Formas'!H2:H5000="Cliente al dia" )
                +( 'Formas'!H2:H5000="Cuenta cesada" )
                +( 'Formas'!H2:H5000="Cliente ocupado" )
                +( 'Formas'!H2:H5000="Volver a llamar" )))

 % RPC
   = RPC / Contactos
   Mayo: 625 / 772  = 80.96%
   Junio: 798 / 940 = 84.89%

 Promesas
   = Promesas (del funnel)

 Promesas cumplidas
   =COUNTIF('Formas'!L2:L5000,"si")   (pagos registrados)

 % Cumplimiento
   = Promesas cumplidas / Promesas
   Mayo: 91 / 115  = 79.13%
   Junio: 100 / 181 = 55.25%

------------- PRODUCTIVIDAD OPERATIVA (hoja datos) -------------
 Llamadas
   =COUNTA('Vici'!A2:A40000) -1   (restar el encabezado si
                                    queda incluido en el rango)
   (columna A del Vici = call_date)
   Mayo: 6,496 llamadas | Junio: 2,159 llamadas

 Contactos
   = contactos efectivos segun Vici (fila con connect/contesto)
   o = Contactadas (del funnel / escenarios contactables)
   Mayo: 772 | Junio: 940

 RPC
   = RPC (contactos productivos)  Mayo: 625 | Junio: 798

 Cant Promesas de pago
   = Promesas (del funnel)  Mayo: 115 | Junio: 181

 % RPC
   = RPC / Contactos

------------- FINANCIEROS POR CANAL (hoja datos) -------------

5) DIAGRAMA ENTIDAD - RELACION (E/R)
----------------------------------------------------------------
 Formato notacion: 1:N = uno a muchos , N:M = muchos a muchos

                   +----------------------------------+
                   |             AGENTE              |
                   |----------------------------------|
                   | id_agente (PK)                  |
                   | nombre_agente                   |
                   | canal_asignado                  |
                   +----------------------------------+
                                 |
                                 | 1
                                 |
                                 | N   (un agente realiza muchas gestiones)
                                 v
+---------------------------+          +------------------------------+
|         BASE_CARTERA      |          |          GESTION (Formas)   |
|---------------------------|          |------------------------------|
| numero_contrato (PK)      |1        N| id_gestion (PK)             |
| cedula (identificacion)   |----------| fecha (marca temporal)      |
| nombre_completo           | 1 --> N  | id_agente (FK)              |
| telefono_cliente          |          | numero_celular              |
| fecha_venta               |          | numero_contrato (FK)        |
| precio / monto_cuotas     |          | canal                       |
| cuotas_pagadas            |          | escenario (tipificacion)    |
| ESTATUS (Al dia/Mora/...) |          | motivo                      |
| DIAS_ATRASO               |          | fecha_promesa               |
| saldo / monto_vencido     |          | monto_promesa               |
+---------------------------+          | realiza_pago (si/no)        |
        |        |                     | fecha_pago                  |
        |        |                     | monto_pagado                |
        |        |                     | dias_mora                   |
        |        |                     +------------------------------+
        |        |                                | 1
        |        | 1                              |
        |        |                                | N  (una cuenta recibe
        |        |                                v     muchas gestiones)
        |        |                     +------------------------------+
        |        |                     |        LLAMADA (Vici)        |
        |        |                     |------------------------------|
        |        |                     | id_llamada (PK)             |
        |        |                     | call_date                   |
        |        |                     | telefono_marcado            |
        |        |                     | status (AB, conectado, etc) |
        |        |                     | user (agente Vici)          |
        |        |                     | campaign_id                 |
        |        |                     | list_id                     |
        |        |                     | numero_contrato (FK)        |
        |        |                     +------------------------------+
        |        |
        |        +------------------------------+
        +--> 1:N (una cuenta en base puede tener
                    muchas llamadas y muchas gestiones)

 RESUMEN DE RELACIONES
  BASE_CARTERA (1) ------< (N) LLAMADA     : una cuenta recibe muchas llamadas
  BASE_CARTERA (1) ------< (N) GESTION     : una cuenta tiene muchas gestiones
  AGENTE (1) ------------< (N) GESTION     : un agente registra muchas gestiones
  AGENTE (1) ------------< (N) LLAMADA     : un agente (user Vici) hace muchas llamadas
  GESTION (N) ------------> (1) BASE       : la gestion pertenece a una cuenta
  LLAMADA (N) ------------> (1) BASE       : la llamada pertenece a una cuenta
  GESTION y LLAMADA se vinculan por el numero de contrato/cuenta

 Los KPI del REPORTE se derivan (no se almacenan):
  REPORTE_JULIO = funcion de ( BASE_CARTERA, LLAMADA, GESTION )
   - Asignadas        <- BASE_CARTERA (cuentas en mora/cero pago)
   - Llamadas/Contactos <- LLAMADA (Vici)
   - Promesas/Pagos   <- GESTION (Formas)
   - Cartera/Recuperacion <- BASE_CARTERA + GESTION

 EN DETALLE, paso 5 (formulas por bloque):
   FUNNEL:   Asignadas --> Base
             Gestionadas --> Formas (cuentas unicas)
             Contactadas --> Formas (escenarios contactables)
             Promesas --> Formas (fecha promesa no vacia)
             Pagos --> Formas (realiza pago = si)
   RESUMEN:  Cartera --> Base (suma saldo en mora)
             Recuperacion --> Formas (sum monto pagado, pago=si)
             % Recuperacion = Recuperacion / Cartera
             Contactabilidad = Contactos / Llamadas
             RPC = contactos productivos
             % RPC = RPC / Contactos
             Promesas cumplidas = Pagos
             % Cumplimiento = Pagos / Promesas
   FINANCIERO: por cada canal --> Formas (monto promesa y monto
             pagado agrupados por Canal)
